WI ย้ายระบบ ESM ขึ้น INET (ฐานข้อมูล Main + DR รวมเป็นฐานเดียว)

ไม่ต้อง reverse engineer — โค้ดทั้งหมดเป็นของเราอยู่ในรีโป และ dump ได้ทั้งโครงสร้างและข้อมูล · การรวม 2 ฐาน แก้ 8 จุดในฐานข้อมูล (สคริปต์ทำให้แล้ว ซ้อมผ่าน) และ ไม่แก้โค้ดหน้าเว็บเลย — เปลี่ยนแค่ค่าตั้งตอน build

สิ่งที่ INET บอกว่า "dump แล้วอัปโหลดใส่ container" — ไฟล์ dump ต้องลง เครื่องฐานข้อมูล (VLAN 1) ไม่ใช่ container ของแอป และ dump ของ Supabase ลง PostgreSQL ธรรมดาตรงๆ ไม่ได้ (มี role/schema/extension เฉพาะ Supabase) ⇒ ต้องลงผ่านสคริปต์รวมฐานของเรา

ห้ามทำ

  • ห้ามส่งไฟล์ dump / รหัสฐาน / service key ทาง LINE · อีเมล · แชท — ไฟล์ dump = ข้อมูลทั้งโรงงาน + รหัสผ่านผู้ใช้ (แบบเข้ารหัส)
  • ห้าม dump ช่วง 08:00–17:30 — ฐานเดิมเครื่องเล็ก หน้างานจะช้า
  • ห้ามปิด/แก้ระบบเดิม จนกว่าจะอนุมัติและนับเทียบผ่านในวันย้ายจริง
  • ห้ามเอา dump ของ Supabase ลงฐานใหม่เองตรงๆ — ต้องผ่าน 20_build_target.sh (มีจุดชน 4 จุด)
  • ห้ามใช้ข้อมูลในระบบ INET เป็นของจริงก่อนวันย้าย — เป็นสำเนา ณ วันที่ dump
